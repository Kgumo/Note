数组与顺序表的关系
**核心规律**：1.逻辑位置比数组下标大1 ，长度为 n时，已有元素位置是 1∼n，插入位置是1∼n+1，第 i个元素对应数组下标 i−1。
插入函数

1. **核心规律：**在逻辑位置 (i) 插入时，应从最后一个元素开始，将数组下标$(i-1\sim length-1)$ 的元素依次向后移动。
2. **最容易错：**循环边界必须包含 `i-1`；同时必须从后往前移动，避免覆盖原数据。
3. **核心规律：**表尾插入不移动元素，为 (O(1))；表头插入需要移动 (n) 个元素，为 (O(n))。
4. **最容易错：**混淆逻辑位置 (i) 与数组下标 (i-1)，或从前往后移动导致数据被覆盖。

### 单链表：在 `p` 结点后插入新结点 `s`

核心代码：

```c
s->next = p->next;
p->next = s;
```

---

### 第一句：新结点接后面

```c
s->next = p->next;
```

翻译：

**把 `p->next` 中保存的地址赋值给 `s->next`。**

也就是：

> **新结点 `s` 先接住 `p` 原来的后继结点。**

原来：

```text
 p
 ↓
┌────┬──────┐       ┌────┬──────┐
│ 20 │ next │ ───→  │ 30 │ next │
└────┴──────┘       └────┴──────┘

 s
 ↓
┌────┬──────┐
│ 99 │  ?   │
└────┴──────┘
```

执行：

```c
s->next = p->next;
```

之后：

```text
 p
 ↓
┌────┬──────┐       ┌────┬──────┐
│ 20 │ next │ ───→  │ 30 │ next │
└────┴──────┘       └────┴──────┘
                         ↑
                         │
                    ┌────┴─────┐
                    │          │
 s                  │
 ↓                  │
┌────┬──────┐       │
│ 99 │ next │ ──────┘
└────┴──────┘
```

此时：

```text
99 → 30
```

但是 `20` 还没有接到 `99`。

---

### 第二句：前面的结点接新结点

```c
p->next = s;
```

翻译：

**把 `s` 中保存的新结点地址赋值给 `p->next`。**

也就是：

> **让前面的结点 `p` 接上新结点 `s`。**

执行后：

```text
 p                  s
 ↓                  ↓
┌────┬──────┐      ┌────┬──────┐      ┌────┬──────┐
│ 20 │ next │ ───→ │ 99 │ next │ ───→ │ 30 │ next │
└────┴──────┘      └────┴──────┘      └────┴──────┘
```

最终：

```text
20 → 99 → 30
```

---

### 记忆口诀

```text
s->next = p->next;
→ 新结点先接后面

p->next = s;
→ 前面的结点再接新结点
```

一句话：

> **先接后面，再接前面。**

### 最重要的区别

```c
s = p->next;
```

→ 改的是 **指针 s 本身**

```c
s->next = p->next;
```

→ 改的是 **s 所指结点里的 next 域**

看到：

```c
A = B;
```

统一翻译：

> **把右边 B 保存的值/地址赋给左边 A。**
