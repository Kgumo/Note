## 2.9

简述以下算法的功能。

### （1）

```c
Status A(LinkedList L) {  // L 是无表头结点的单链表
    if (L && L->next) {
        Q = L;
        L = L->next;
        P = L;

        while (P->next)
            P = P->next;

        P->next = Q;
        Q->next = NULL;
    }

    return OK;
} // A
```

### （2）

```c
void BB(LNode *s, LNode *q) {
    p = s;

    while (p->next != q)
        p = p->next;

    p->next = s;
} // BB

void AA(LNode *pa, LNode *pb) {
    // pa 和 pb 分别指向单循环链表中的两个结点
    BB(pa, pb);
    BB(pb, pa);
} // AA
```

## 2.10

本题涉及的顺序表类型定义如下：

```c
#define LIST_INIT_SIZE 100
#define LISTINCREMENT 10

typedef struct {
    ElemType *elem;  // 存储空间基址
    int length;      // 当前长度
    int listsize;    // 当前分配的存储容量
} SqList;            // 顺序表类型
```

指出以下算法中的错误和低效（即费时）之处，并将它改写为一个既正确又高效的算法。

```c
Status DeleteK(SqList &a, int i, int k) {
    // 本过程从顺序存储结构的线性表 a 中删除第 i 个元素起的 k 个元素
    if (i < 1 || k < 0 || i + k > a.length)
        return INFEASIBLE;  // 参数不合法
    else {
        for (count = 1; count < k; count++) {
            // 删除一个元素
            for (j = a.length; j >= i + 1; j--)
                a.elem[j - 1] = a.elem[j];

            a.length--;
        }
    }

    return OK;
} // DeleteK
```
