### 📚 考研常用泰勒展开式（麦克劳林公式）速记表

|函数|展开式（含皮亚诺余项）|核心记忆特征|
|---|---|---|
|**$e^x$**|$1 + x + \frac{1}{2!}x^2 + \frac{1}{3!}x^3 + o(x^3)$|**全正号，带阶乘**（万物之源，各项连续不断）|
|**$\sin x$**|$x - \frac{1}{3!}x^3 + \frac{1}{5!}x^5 + o(x^5)$|**奇函数**（仅奇数次幂），正负交替，带阶乘|
|**$\cos x$**|$1 - \frac{1}{2!}x^2 + \frac{1}{4!}x^4 + o(x^4)$|**偶函数**（仅偶数次幂），正负交替，带阶乘|
|**$\frac{1}{1-x}$**|$1 + x + x^2 + x^3 + o(x^3)$|**全正号，无阶乘**（等比数列求和基础形）|
|**$\frac{1}{1+x}$**|$1 - x + x^2 - x^3 + o(x^3)$|**正负交替，无阶乘**|
|**$\ln(1+x)$**|$x - \frac{1}{2}x^2 + \frac{1}{3}x^3 - \frac{1}{4}x^4 + o(x^4)$|**正负交替，无阶乘**（分母就是数字本身）|
|**$\ln(1-x)$**|$-x - \frac{1}{2}x^2 - \frac{1}{3}x^3 - \frac{1}{4}x^4 + o(x^4)$|**全负号，无阶乘**（把上式的 $x$ 换成 $-x$）|
|**$\tan x$**|$x + \frac{1}{3}x^3 + o(x^3)$|**全正号，无阶乘**（极易与 $\sin x$ 混淆，注意符号）|
|**$\arcsin x$**|$x + \frac{1}{6}x^3 + o(x^3)$|**全正号，分母为 6**（可以当成有 $3!$ 的阶乘感）|
|**$\arctan x$**|$x - \frac{1}{3}x^3 + o(x^3)$|**正负交替，无阶乘**|
|**$(1+x)^\alpha$**|$1 + \alpha x + \frac{\alpha(\alpha-1)}{2!}x^2 + o(x^2)$|常用二项式展开，只需记前三项。当 $\alpha=\frac{1}{2}$ 时为 $\sqrt{1+x}$|

### 💡 考场防串台检查清单

- **看阶乘**：指数（$e^x$）、正弦（$\sin x$）、余弦（$\cos x$）**有阶乘**；对数（$\ln$）、正切（$\tan x$）**无阶乘**。
- **看正负**：$e^x$、$\frac{1}{1-x}$、$\tan x$、$\arcsin x$ 是**全正号**（或同号）；三角函数（$\sin, \cos$）、$\ln(1+x)$ 是**正负交替**。
- **看奇偶**：原函数是奇函数，展开式绝对没有偶数次幂；原函数是偶函数，绝对没有奇数次幂。
