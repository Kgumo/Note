| **consciousness** | 意识、知觉 | **lose consciousness** (失去知觉) |
| **consequently** | 因此、结果 | 相当于 **therefore**，用于写作提分 |
| **arbitrary** | 武断的、任意的 | 联想：仲裁者(arbiter)如果武断就很可怕 |
| **anecdote** | 趣闻、轶事 | 谐音“爱尼克豆特” → 爱讲有趣的故事 |
| **allocate** | 分配、拨出 | 搭配：**allocate funds for** (拨款给…) |
| **corruption** | 贪污、腐败 | 政治类高频词 |
| **altitude** | 海拔、高度 | 对比：**attitude** (态度) 字母不同 |
| **antique** | 古董 | 形容词：古老的 |

## 📚 第3类：形近词 / 易混词辨析
你在翻译中偶尔会把长得像的词搞混，明天可以专门看一下这组对比：

1. **adapt vs. adopt vs. adept**  
   - 虽然没直接出现，但你是容易混淆这类词的类型。
2. **personal** (个人的) vs. **personnel** (人事/员工)  
   - 第1轮中出现的“personal preference”就是“个人偏好”。
3. **considerate** (体贴的) vs. **considerable** (大量的)  
   - 四级阅读常考。
