## 1. 任务定义与模型核心原理 (Task & Model Principles)
### 1.1 任务描述
本实验的任务目标是模拟法律专业人士的阅读推理过程。给定一段案情描述（Context）与一个自然语言问题（Question），模型需完成三个耦合的子任务：首先是**答案定位**，即在文书中截取回答问题的具体文本片段；其次是**类型判断**，判断答案属于具体片段（SPAN）还是“YES/NO/UNKNOWN”类别；最后是**佐证预测**，即从案情中筛选出支持判决依据的关键句子集合，这是实现可解释性推理的关键。
### 1.2 模型架构详解
为了解决上述多任务挑战，本研究构建了基于 Transformer 的编码器-解码器架构。
**（1）输入表示与编码器**  
模型采用拼接输入方式：`[CLS] Question [SEP] Context [SEP]`。利用 Transformer 的自注意力机制，让模型在编码阶段就能同时关注问题和案情，捕捉两者间的语义交互。底层使用预训练模型（如 BERT 或 RoBERTa）将离散的 Token 序列映射为上下文感知的稠密向量 $H \in \mathbb{R}^{L \times d}$，其中 `[CLS]` 向量被视为整个输入序列的全局语义表示。
**（2）多任务预测层**  
模型在编码器顶层设计了三个并行的预测模块。
**指针网络（Span Head**利用两个独立的全连接层分别预测答案起始位置和结束位置的概率分布；
**分类网络（Type Head**利用全局最大池化特征通过 Softmax 进行 4 分类预测；
**佐证预测网络（SP Head**则是本模型的难点，它首先对属于第 $k$ 个句子的所有 Token 向量进行最大池化得到句子级表示 $S_k$，随后通过一个 Sigmoid 激活层进行二分类预测，判断该句是否为佐证。
### 1.3 联合优化目标
为了平衡三个任务的学习，模型采用了联合损失函数。总损失由跨度预测的交叉熵损失、类型分类的交叉熵损失以及佐证预测的二元交叉熵损失加权求和而成。这种多任务联合训练机制使得模型能够在不同任务间共享底层语义特征，从而提升整体泛化能力。

## 2. 基线模型复现与评测 (Baseline Implementation)
本研究首先基于 `bert-base-chinese` 构建了基线系统。实验环境基于 PyTorch 框架，采用 Native AMP（自动混合精度）技术加速训练，以适应显存限制。我们将 Learning Rate 设置为 1e-4，并通过梯度累积（Gradient Accumulation）将等效 Batch Size 设为 32，训练周期为 5 个 Epoch。
在开发集（Dev Set）上的评测结果显示，基线模型取得了 **Answer F1: 71.49%** 和 **Joint F1: 41.67%** 的成绩。这一结果表明基线代码逻辑正确，模型能够初步理解法律文本并进行简单的答案抽取，但对于需要结合佐证事实进行复杂逻辑推理的样本，基线模型仍有显著的提升空间。

## 3. 进阶探索与优化 (Exploration and Optimization)
为了突破基线模型的性能瓶颈，本研究在现有代码基础上进行了层层递进的改进实验，分别针对语义理解的颗粒度、证据链的逻辑建模以及训练数据的规模进行了优化。
### 3.1 探索一：预训练模型的升级 (RoBERTa-wwm)
**改进动机**：  
基线 BERT 模型采用字级别（Character-level）掩码，这在处理法律文本时容易割裂语义。例如，“非法持有毒品罪”若只掩盖了“毒”字，模型只需根据搭配即可猜出，而无需理解整个罪名的含义。为此，本研究引入了 **RoBERTa-wwm-ext** 模型，利用其**全词掩码** 特性，强制模型预测被掩盖的整个词汇，从而学习更完整的语义表征。
**过程分析**：  
在实验过程中，我们发现 RoBERTa 对优化器超参数表现出高度敏感性。初期遵循官方建议使用低学习率（3e-5）导致模型收敛缓慢，性能甚至低于基线。经过分析，我们认为在特定领域的微调任务中，数据量较小且迭代次数有限，过低的学习率会导致模型陷入局部最优。将学习率调整回 1e-4 后，RoBERTa 的性能得到释放，Answer F1 提升至 **72.43%**（+0.94%），证明了更强的语义表征对司法阅读理解的关键作用。
### 3.2 探索二：架构创新——基于图神经网络的逻辑建模
**改进动机**：  
司法推理本质上是证据链的构建过程，佐证事实之间往往存在“事实A $\rightarrow$ 事实B $\rightarrow$ 结论”的逻辑依赖。基线模型独立预测每个句子，忽略了这种篇章级的上下文交互。
**方法实现**：  
本研究设计并实现了一个**图注意力模块 (GNN)**（详见代码 `model/modeling_gnn.py`）。具体而言，模型将文档中的每个句子视为图中的一个节点。利用 **Self-Attention** 机制模拟全连接图结构，使每个句子节点能够根据注意力权重聚合全文其他句子的信息。这种机制赋予了模型“全局视野”，使其能够识别出成组出现的证据链。最后，通过残差连接将 GNN 增强后的逻辑特征与原始 BERT 语义特征融合。
**结果分析**：  
引入 GNN 后，模型的 Answer F1 进一步提升至 **72.83%**，且 Answer EM（完全匹配率）达到 **63.29%** 的最优水平。Joint F1 的同步提升证明：显式的句间交互机制成功帮助模型捕捉到了佐证事实间的逻辑依赖，从而更精准地定位了答案。
### 3.3 探索三：数据增强方案的设计与反思
**方案设计**：  
针对训练数据稀缺（仅 5,000 条）导致的潜在过拟合风险，本研究设计了引入 CJRC 2019 大规模数据集（约 40,000+ 条）的增强方案。由于 CJRC 数据缺乏佐证标注，本研究编写了 `tools/convert_cjrc.py` 转换脚本，采用**远程监督** 思想，通过启发式规则将包含答案的句子标记为伪标签佐证。
**结果反思**：  
实验结果显示，直接混合增强数据训练后，模型 F1 分数反而轻微下滑至 71.10%。经过深度归因分析，主要原因在于**标签噪声 (Label Noise)**。远程监督规则过于粗糙，将很多仅提及实体但非判决依据的句子错误标记为佐证，导致模型拟合了错误的推理逻辑。这一负面结果反向证明了：在利用大规模无标注数据时，必须引入标签清洗或置信度过滤机制，数据质量的重要性优于数据数量。

## 4. 实验结果汇总与讨论 (Results and Discussion)
本实验统一在 PyTorch 框架下进行，采用 Native AMP 混合精度加速训练。在开发集（Dev Set）上的最终评测结果汇总如下：

| 实验阶段        | 模型架构              | 预训练权重           | Answer F1  |  Joint F1  | 结果深度分析                     |
| :---------- | :---------------- | :-------------- | :--------: | :--------: | :------------------------- |
| **Phase 1** | Baseline          | BERT-Base       |   71.49%   |   41.67%   | 基准性能，验证了多任务框架的有效性。         |
| **Phase 2** | RoBERTa           | RoBERTa-wwm     |   72.43%   |   44.36%   | 全词掩码显著增强了实体识别能力，提升了约 1%。   |
| **Phase 3** | **RoBERTa + GNN** | **RoBERTa-wwm** | **72.83%** | **44.40%** | **最优结果。句间交互机制提升了逻辑推理精度。**  |
| **Phase 4** | Data Aug          | RoBERTa-wwm     |   71.10%   |   43.70%   | 远程监督引入的噪声导致性能回落，提示需进行噪声清洗。 |
从数据可以看出，RoBERTa 的引入主要带来了语义层面的收益，而 GNN 的加入则进一步解决了逻辑层面的问题，两者的结合（Phase 3）构成了本次实验的最佳实践。

---
## 5. 结论 (Conclusion)
本实验通过系统的复现与探索，成功构建了一个高性能的司法阅读理解模型。研究表明：第一，针对中文法律文本，全词掩码技术（WWM）比字掩码更具优势；第二，将篇章级的句子关系建模为图结构，并利用注意力机制进行特征聚合，是解决多步推理问题的有效手段；第三，在数据增强方面，简单的远程监督策略容易引入噪声，未来的工作应重点关注噪声标签学习（Noisy Label Learning）以利用大规模异构数据。
